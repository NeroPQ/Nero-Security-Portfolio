Spring4ShellCVE-2022-22965

Reproduced command execution through a Spring Framework data-binding vulnerability in a TryHackMe lab.

CVSS BASE SCORE9.8
RESEARCH AREARemote Code Execution
LAB OUTCOMERemote command execution
01 / RESEARCH

Investigation approach

Used the provided lab PoC to exercise a Tomcat/JSP attack path and documented HTTP output indicating command execution under the target account.

02 / ROOT CAUSE

What made it possible

Unsafe data binding can expose internal Java class-loading paths when vulnerable application and deployment prerequisites are met.

03 / EVIDENCE

What the lab demonstrated

  • Lab PoC source archived
  • HTTP response documented
  • whoami returned root
  • Two screenshots and an evidence log
04 / SCOPE

Limitations

Exact Spring, JDK and Tomcat versions were not captured; id output was not independently visible.

Original research files

Source material and screenshots are preserved in the public GitHub repository.
