PwnKitCVE-2021-4034

Reproduced local privilege escalation in pkexec with the public PwnKit proof of concept in an authorized lab.

CVSS BASE SCORE7.8
RESEARCH AREALocal Privilege Escalation
LAB OUTCOMERoot privileges
01 / RESEARCH

Investigation approach

Studied SUID execution and pkexec argument processing, reproduced the public PoC and confirmed the privilege boundary crossing using identity commands and root-only lab file access.

02 / ROOT CAUSE

What made it possible

Out-of-bounds access in pkexec when processing an empty argument vector, interacting with environment handling.

03 / EVIDENCE

What the lab demonstrated

  • Compiled and executed public PoC
  • whoami returned root
  • id returned uid=0(root)
  • Root-only lab file access (flag redacted)
04 / SCOPE

Limitations

The exact Linux distribution and polkit package build were not captured in the supplied lab evidence.

Original research files

Source material and screenshots are preserved in the public GitHub repository.
