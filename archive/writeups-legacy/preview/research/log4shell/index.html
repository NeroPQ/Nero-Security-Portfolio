Log4ShellCVE-2021-44228

A vulnerable Log4j lookup path in Apache Solr led to a JNDI callback, Java class retrieval and verified command execution.

CVSS BASE SCORE10.0
RESEARCH AREARemote Code Execution
LAB OUTCOMEUser-level RCE
01 / RESEARCH

Investigation approach

Investigated the JNDI/LDAP lookup flow, configured a controlled LDAP referral and HTTP delivery path, then correlated reverse-connection evidence with operating system command output.

02 / ROOT CAUSE

What made it possible

Unsafe processing of attacker-controlled JNDI lookup expressions in affected Log4j2 configurations.

03 / EVIDENCE

What the lab demonstrated

  • LDAP referral for the hosted class
  • HTTP GET /Exploit.class with status 200
  • Reverse connection to listener
  • whoami, id, hostname and pwd on target
04 / SCOPE

Limitations

User-level access was verified; root access and post-patch validation were not demonstrated. Version checks were recorded on an earlier lab instance.

Original research files

Source material and screenshots are preserved in the public GitHub repository.
